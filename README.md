# گل‌آرا 🌸 — فروشگاه اینترنتی لوازم آرایشی

پروژه عملی دوره جامع PHP (دانشجویار) — یه فروشگاه اینترنتی با PHP رویه‌ای و شی‌گرا، MySQL، Ajax، روتر و API، درگاه پرداخت زرین‌پال، دستیار هوش مصنوعی و ربات تلگرام.

## امکانات

- **فروشگاه:** صفحه اصلی، فهرست محصولات با فیلتر/مرتب‌سازی/صفحه‌بندی، جستجوی زنده، صفحه محصول (موجودی، امتیاز، بزرگ‌نمایی عکس، محصولات مشابه)، علاقه‌مندی‌ها، نظرات
- **سبد خرید:** برای مهمان تو سشن و برای کاربر واردشده تو دیتابیس؛ کنترل موجودی، سقف تعداد، کد تخفیف، هزینه ارسال (رایگان بالای آستانه)، همگام‌سازی بین تب‌ها
- **سفارش:** آدرس تحویل، رزرو موجودی انبار، پرداخت با زرین‌پال (Sandbox)، فاکتور قابل چاپ، وضعیت ارسال و کد رهگیری
- **حساب کاربری:** ثبت‌نام/ورود، بازیابی رمز با ایمیل، تغییر رمز، سفارش‌ها
- **پنل مدیریت:** سفارش‌ها (فیلتر، وضعیت ارسال)، محصولات (جستجو/فیلتر/صفحه‌بندی، حذف نرم و بازگردانی)، دسته‌بندی‌ها، کدهای تخفیف، کلیدهای API
- **API:** روتر (`Router`) + کنترلرها، قالب خروجی یکدست، کلیدهای API هش‌شده
- **امنیت، سئو، دسترس‌پذیری:** پایین‌تر توضیح داده شده

## پیش‌نیازها

- [XAMPP](https://www.apachefriends.org/) (Apache + MySQL/MariaDB + PHP 8.1 یا بالاتر) با ماژول‌های `mod_rewrite` و `mod_headers` (و بهتر است `mod_deflate`)، و افزونه‌های PHP: `mysqli`, `gd` (با WebP), `fileinfo`, `mbstring`, `curl`
- [Composer](https://getcomposer.org/) (یا همون `composer.phar` که کنار پروژه هست)
- یه مرورگر

## نصب (قدم‌به‌قدم)

### ۱. کپی پروژه
فایل‌ها رو هرجا که می‌خوای قرار بده؛ اسم پوشه مهم نیست و هیچ آدرسی تو کد ثابت نشده. دو حالت رایجه:

- **زیرپوشه** تو `htdocs` اکسمپ (مثلاً `C:\xampp\htdocs\golara`) و باز کردن با `http://localhost/golara/`
- **دامنه اختصاصی** (Virtual Host / Laragon، مثلاً `http://golara-store.test`) با Document Root روی **همین پوشه پروژه**

آدرس پایه سایت (`config/app.php`) خودکار از روی دامنه و مسیر تشخیص داده می‌شه. اگه خواستی دستی ثابتش کنی، تو `.env` مقدار `APP_URL` رو بذار.

> فایل‌های `.htaccess` (نیاز به `AllowOverride All`) جلوی دانلود `.env`، `vendor`، `config`، `classes`، `database`، `storage` و ... رو می‌گیرن، `robots.txt` و `sitemap.xml` رو می‌سازن، و تو پوشه `uploads/` اجرای هر اسکریپتی رو می‌بندن.

### ۲. ساخت دیتابیس
Apache و MySQL رو از پنل کنترل XAMPP روشن کن، بعد فایل `database/install.sql` رو تو phpMyAdmin ایمپورت کن (یا از خط فرمان):

```bash
mysql -u root < database/install.sql
```

همه جدول‌ها و داده‌های اولیه (دسته‌بندی، ۱۲ محصول نمونه با موجودی، دو کد تخفیف نمونه) ساخته می‌شن. **اکانت ادمین و کلید API ساخته نمی‌شن** (رمز و کلید ثابت تو ریپوی عمومی یعنی هر کسی می‌تونه ازشون استفاده کنه)؛ مرحله ۶ رو ببین.

**دیتابیس نسخه‌ی قبلی داری؟** به‌جای ساخت دوباره، مهاجرت‌ها رو اجرا کن (فقط تغییرهای جدید رو اعمال می‌کنه و هرکدوم یک بار):

```bash
php bin/migrate.php
```

### ۳. تنظیم متغیرهای محیطی
فایل `.env.example` رو کپی کن و اسمش رو بگذار `.env`، بعد مقادیرش رو پر کن:

```bash
cp .env.example .env
```

| متغیر | توضیح |
|---|---|
| `APP_URL` | (اختیاری) آدرس پایه سایت. خالی = تشخیص خودکار |
| `APP_DEBUG` | `true` = جزئیات خطای API نشون داده بشه (فقط موقع توسعه) |
| `DB_HOST`, `DB_USER`, `DB_PASS`, `DB_NAME` | اطلاعات اتصال دیتابیس (پیش‌فرض XAMPP: `root` بدون رمز) |
| `SHOP_NAME`, `SHOP_PHONE`, `SHOP_WHATSAPP`, `SHOP_EMAIL`, `SHOP_ADDRESS` | مشخصات فروشگاه؛ هرچی خالی باشه تو سایت نشون داده نمی‌شه (دکمه واتساپ فقط با `SHOP_WHATSAPP` میاد، به شکل `989121234567`) |
| `FREE_SHIPPING_THRESHOLD`, `SHIPPING_COST` | آستانه ارسال رایگان و هزینه ثابت ارسال (تومان) |
| `ADMIN_SETUP_KEY` | (اختیاری) کلیدی که برای ساخت اولین مدیر لازمه؛ روی سرور اینترنتی حتماً بذارش |
| `MAIL_DRIVER`, `MAIL_FROM` | `log` (پیش‌فرض: ایمیل‌ها تو `storage/mail.log` نوشته می‌شن) یا `mail` (ارسال واقعی با `mail()` روی هاست) |
| `GEMINI_API_KEY` | کلید رایگان از [aistudio.google.com/apikey](https://aistudio.google.com/apikey) — برای دستیار هوشمند |
| `ZARINPAL_MERCHANT_ID` | برای تست، همون `00000000-0000-0000-0000-000000000000` کافیه (Sandbox) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ADMIN_CHAT_ID` | برای اطلاع‌رسانی سفارش جدید (همراه با آدرس تحویل) تو تلگرام (اختیاری) |

> بدون کلیدهای Gemini و تلگرام هم سایت کامل کار می‌کنه؛ فقط چت هوشمند و اعلان تلگرام غیرفعال می‌مونن.

### ۴. نصب پکیج‌های Composer
```bash
php composer.phar install
```
(اگه Composer رو جدا نصب کردی، به‌جاش بزن: `composer install`)

### ۵. اجرا
برو به آدرس پروژه، مثلاً `http://localhost/golara/` یا `http://golara-store.test/`

### ۶. ساخت اولین مدیر
اولین بار که `/admin/` رو باز کنی، فرم «ساخت اولین مدیر» میاد؛ نام کاربری و رمز دلخواهت رو بده (حداقل ۸ کاراکتر، حرف و عدد). بعد از ساخت، این فرم برای همیشه بسته می‌شه.
اگه از نسخه‌ی قبلی ارتقا دادی و هنوز با رمز قدیمی `admin123` وارد می‌شی، سایت مجبورت می‌کنه همون لحظه رمزت رو عوض کنی.

**کلید API:** از `پنل مدیریت ← کلیدهای API` بساز؛ کلید فقط یک بار نشون داده می‌شه و تو دیتابیس فقط هش SHA-256 اون ذخیره می‌شه.

## راهنمای تست (چی رو کجا ببینم)

### فروشگاه عمومی
- **صفحه اصلی:** پرفروش‌ترین‌ها (بر اساس تعداد فروش واقعی سفارش‌های پرداخت‌شده؛ تا فروشی نباشه جدیدترین‌ها)، دسته‌بندی‌ها، خبرنامه (Ajax + ایمیل تأیید)
- **`products.php`:** فیلتر دسته/قیمت/موجودی، مرتب‌سازی، صفحه‌بندی (۸ محصول در هر صفحه)؛ روی موبایل فیلتر جمع‌شده‌ست
- **`search.php`:** جستجوی زنده (Ajax + debounce)
- **صفحه محصول:** محصول `16` ناموجوده و `8` فقط ۳ عدد موجودی داره؛ روی عکس بزن تا بزرگ بشه

### سبد، تخفیف و پرداخت
1. چند محصول به سبد اضافه کن (از کارت محصول یا صفحه محصول). بیشتر از موجودی یا بیشتر از ۱۰ عدد از یه کالا قبول نمی‌شه.
2. تو صفحه سبد کد `GOLARA10` (۱۰٪ برای خرید بالای ۵۰۰ هزار تومان) یا `WELCOME50` (۵۰ هزار تومان برای خرید بالای ۳۰۰ هزار) رو امتحان کن. زیر ۲ میلیون تومان، ۸۰ هزار تومان هزینه ارسال اضافه می‌شه.
3. «ادامه» → ثبت‌نام/ورود (سبد مهمان بعد از ورود حفظ می‌شه) → آدرس تحویل (اعتبارسنجی موبایل و کدپستی، ارقام فارسی هم قبوله) → پرداخت. موجودی همون لحظه رزرو می‌شه.
4. تو صفحه زرین‌پال فقط کافیه رو دکمه «پرداخت» بزنی (Sandbox). لغو پرداخت یا ۳۰ دقیقه رهاکردن، موجودی رو برمی‌گردونه.
5. `سفارش‌های من ← جزئیات و فاکتور`: فاکتور، وضعیت ارسال، کد رهگیری و دکمه چاپ.

### چند تب
سایت رو تو دو تب باز کن؛ افزودن/حذف محصول از سبد یا علاقه‌مندی تو یه تب، بدون رفرش تو تب دیگه (شمارنده‌ها، قلب‌ها، صفحه سبد و علاقه‌مندی) نشون داده می‌شه (`BroadcastChannel`). سبد و علاقه‌مندی کاربر واردشده تو دیتابیسه و از هر دستگاهی همونه.

### پنل مدیریت (`/admin/`)
- **سفارش‌ها:** آمار، جستجو، فیلتر پرداخت/ارسال، تغییر وضعیت ارسال و ثبت کد رهگیری
- **محصولات:** جستجو، فیلتر دسته/موجودی/حذف‌شده، مرتب‌سازی، صفحه‌بندی. «حذف» یعنی **حذف نرم**: محصول از فروشگاه پنهان می‌شه ولی تاریخچه سفارش‌ها و آمار فروش می‌مونه؛ با فیلتر «حذف‌شده» بازگردانی می‌شه.
- افزودن (Ajax) و ویرایش محصول با آپلود امن عکس (فقط JPEG/PNG/WebP واقعی، حداکثر ۲ مگابایت، دوباره‌ساخته‌شده، اسم تصادفی)
- **دسته‌بندی‌ها، کدهای تخفیف، کلیدهای API**

### API
همه درخواست‌های `/api/...` وارد `api/index.php` می‌شن و **روتر** (`classes/Router.php`) با (متد HTTP + آدرس) کنترلر مناسب (`classes/Api/*Controller.php`) رو پیدا می‌کنه. خروجی همه‌جا یک قالبه:

```json
{ "success": true,  "message": "...", "data": { } }
{ "success": false, "message": "...", "errors": { "price": "..." } }
```
کد وضعیت HTTP هم درست برمی‌گرده (۲۰۰/۲۰۱ موفق، ۴۰۱ نیاز به ورود/کلید، ۴۰۳ CSRF، ۴۰۴، ۴۰۵، ۴۰۹ کمبود موجودی، ۴۲۲ ورودی نامعتبر، ۴۲۹ تعداد درخواست زیاد).

| متد و آدرس | توضیح |
|---|---|
| `GET /api/v1/products?page=&per_page=&q=&category_id=&in_stock=1&min_price=&max_price=&sort=` | لیست با فیلتر و صفحه‌بندی (`sort`: newest, oldest, price_asc, price_desc, name, bestseller) |
| `GET /api/v1/products/{id}` | جزئیات یک محصول |
| `POST` / `PUT` / `DELETE` ‏`/api/v1/products[/{id}]` | ساخت / ویرایش / حذف نرم (هدر `X-API-Key`) |
| `GET /api/v1/categories`، `GET /api/v1/categories/{id}` | دسته‌بندی‌ها (با تعداد محصول) |
| `POST` / `PUT` / `DELETE` ‏`/api/v1/categories[/{id}]` | مدیریت دسته‌بندی (هدر `X-API-Key`) |

خواندن (GET) از هر دامنه‌ای مجازه (CORS)؛ تغییرها فقط با کلید API و **بدون** CORS، چون کلید باید سمت سرور بمونه. هر کلید در دقیقه حداکثر ۱۲۰ درخواست تغییردهنده داره.

مسیرهای زیر برای خود صفحه‌های سایت‌ان (سشن + هدر `X-CSRF-Token`): `GET /state`، `GET /cart`، `PUT|DELETE /cart/coupon`، `POST /cart/items`، `PATCH|DELETE /cart/items/{productId}`، `GET /wishlist`، `PUT|DELETE /wishlist/{id}`، `GET /search`، `POST /newsletter`، `POST /products/{id}/reviews`، `POST|DELETE /assistant/messages`، `POST /admin/products`.

```bash
# لیست محصولات (بدون نیاز به کلید)
curl "http://golara-store.test/api/v1/products?per_page=5&sort=price_desc"

# ساخت محصول جدید (کلید رو از پنل مدیریت بساز)
curl -X POST http://golara-store.test/api/v1/products \
  -H "Content-Type: application/json" \
  -H "X-API-Key: <کلید>" \
  -d '{"name":"تست","price":100000,"stock":10,"category_id":1}'
```
بدون `mod_rewrite` هم می‌شه با `http://.../api/index.php/v1/products` صدا زد.

### تست خودکار
```bash
php tests/run.php
```
یه دیتابیس موقت از روی `install.sql` می‌سازه، حدود ۱۱۰ تست رو اجرا می‌کنه (قوانین موجودی، رزرو و لغو سفارش، ادغام سبد، کد تخفیف، نرخ‌محدودی، کلید API، بازیابی رمز، خبرنامه، روتر و ...) و آخرش پاکش می‌کنه؛ به دیتابیس اصلی دست نمی‌زنه.

## امنیت

- **دیتابیس:** Prepared Statement همه‌جا (ضد SQL Injection)؛ قید `UNIQUE` روی نظرات؛ کم‌کردن موجودی اتمیک (`UPDATE ... WHERE stock >= n`) داخل تراکنش؛ ردیف خرید سفارش‌ها با `RESTRICT` محافظت شده
- **ورود:** نرخ‌محدودی بر اساس **IP و حساب تو دیتابیس** (با پاک‌کردن کوکی دور زده نمی‌شه)، کپچای ریاضی، یکسان‌بودن زمان پاسخ برای ایمیل موجود/ناموجود، سیاست رمز (۸ کاراکتر، حرف و عدد)، تعویض اجباری رمز پیش‌فرض قدیمی ادمین، بدون رمز پیش‌فرض تو نصب تازه
- **سشن:** `HttpOnly`، `SameSite=Lax`، `Secure` (فقط روی HTTPS؛ روی `http://` مرورگر کوکی `Secure` رو قبول نمی‌کنه)، حالت strict، تعویض شناسه بعد از ورود
- **CSRF:** توکن روی همه فرم‌ها و درخواست‌های Ajax؛ خروج فقط با POST؛ تسویه حساب فقط با POST
- **XSS:** `htmlspecialchars` روی همه خروجی‌ها + هدر `Content-Security-Policy` سخت‌گیرانه (فقط اسکریپت‌ها و فونت‌های خود سایت؛ هیچ اسکریپت inline ای نیست)
- **هدرها:** `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, (روی HTTPS) `Strict-Transport-Security`؛ `X-Powered-By` حذف شده
- **آپلود:** بررسی محتوای واقعی فایل، حجم و ابعاد، بازسازی با GD (متادیتا و کد پنهان پاک می‌شه)، اسم تصادفی، و اجرای اسکریپت تو `uploads/` بسته‌ست
- **پرداخت:** برگشت از درگاه فقط با `Authority` درست پذیرفته می‌شه (قبلاً با عوض‌کردن `order_id` می‌شد سفارش بقیه رو لغو کرد یا رسیدشون رو دید)؛ مبلغ نهایی همیشه سمت سرور دوباره محاسبه می‌شه
- **API:** کلیدها هش‌شده، چند کلید جدا (قابل ابطال)، نرخ‌محدودی کلید و IP، CORS فقط برای خواندن

## سئو و دسترس‌پذیری

عنوان و توضیح مخصوص هر صفحه، `canonical`، Open Graph، داده ساختاریافته (Organization، WebSite، Product با قیمت/موجودی/امتیاز، BreadcrumbList)، مسیر ناوبری، `robots.txt` و `sitemap.xml` پویا، `favicon`، صفحه‌های خصوصی/فیلترشده `noindex`. یک `h1` در هر صفحه، لینک «پرش به محتوا»، منوی قابل‌استفاده با کیبورد، `aria-label`/`aria-pressed` روی دکمه‌ها، کنتراست حداقل ۴٫۵:۱، اسلایدر قابل‌توقف و بی‌حرکت در حالت `prefers-reduced-motion`.

## سرعت

فونت از خود سایت (نه Google Fonts)، عکس‌ها به‌صورت خودکار به نسخه‌ی کوچک WebP با ابعاد ثابت (`width`/`height`، بدون پریدن صفحه) تبدیل و کش می‌شن، کش طولانی برای CSS/JS/فونت (با `?v=` تغییر نسخه)، فشرده‌سازی (اگه `mod_deflate` فعال باشه)، و کوئری مجموع فروش فقط وقتی لازمه که بر اساس پرفروش‌ها مرتب کنی.

## نکات انتشار روی سرور واقعی
